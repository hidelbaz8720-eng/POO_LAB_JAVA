# 🚗 Lab Java — Création et manipulation de la classe `Voiture`

Ce projet est un laboratoire réalisé dans le cadre de l'apprentissage de la **programmation orientée objet (POO) en Java**.

L'objectif est de créer et manipuler une classe `Voiture` afin de mettre en pratique les principales notions de la programmation orientée objet.

## 🎯 Objectifs

Dans ce laboratoire, j'ai travaillé sur :

* La création d'une classe Java.
* La déclaration d'attributs privés.
* Les constructeurs :

  * constructeur par défaut ;
  * constructeur paramétré ;
  * constructeur de copie.

## 🛠️ Technologies utilisées

* **Java**
* **Programmation Orientée Objet (POO)**
* **IDE Java**

## 📂 Structure du projet

```text
lab/
├── Voiture.java
└── TestVoiture.java
```

### `Voiture.java`

Contient la classe `Voiture`, ses attributs, constructeurs, getters/setters, validations et méthodes métier.

### `TestVoiture.java`

Contient la méthode `main` permettant de créer plusieurs voitures, de modifier leurs données et de tester leur comportement.

## 🧠 Notions principales

Ce laboratoire m'a permis de mieux comprendre le fonctionnement des **objets et des classes en Java**, ainsi que l'intérêt de l'**encapsulation** et des **constructeurs** pour gérer correctement les données d'un objet.
